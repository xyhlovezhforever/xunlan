# 玄览术数资料库

React + Vite 构建的传统文化资料网站，包含：

- 先天八卦序数、方位与象义
- 六十四卦卦辞与白话提示
- 小六壬六宫、掌上定位与三步起法
- Rider Waite 体系完整 78 张塔罗牌义

## 本地开发

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://127.0.0.1:5173/`。

## 生产构建

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。

## 目录说明

- `src/App.jsx`：页面组件与交互
- `data.js`：八卦、六十四卦与小六壬资料
- `tarot-data.js`：完整 78 张塔罗牌资料
- `styles.css`：全站视觉与响应式样式

资料仅供传统文化学习与自我反思，不替代医疗、法律、投资或人生重大决策。
